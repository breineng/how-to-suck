# Архив прототипов

Эта папка содержит ранние сцены разработки. Актуальные игровые сцены, окружение и запечённое освещение находятся в `Assets/_Game/Production/Scenes`.

Запуск игры: меню Unity **How to Suck → Играть**, либо обычная кнопка Play. Стартовая сцена — `ProductBootstrap`.

Для просмотра актуальных уровней используйте **How to Suck → Сцены**: Старый дом, Супермаркет, Склад. Старые прототипы исключены из списка сборки.
