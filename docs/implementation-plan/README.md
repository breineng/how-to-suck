# How to Suck — документация

## Как читать дизайн

[How_to_Suck_GDD.md](../How_to_Suck_GDD.md) содержит первую версию дизайна. Её развитие от 6 сентября 2026 года сохранено отдельно в [How_to_Suck_GDD_updated.md](../How_to_Suck_GDD_updated.md) с исходной нумерацией разделов. Документы описывают целевую игру; состояние реализации и текущие численные параметры определяются кодом и Unity-ресурсами.

- [Подтверждённые правила](../design-updates/2026-09-06-confirmed-gameplay-handoff.md) выделяют основные требования GDD.
- [Рабочие решения](../design-updates/2026-09-06-gameplay-working-decisions.md) связывают эти правила с реализацией.
- [Проверка игрового цикла](tasks/21-gameplay-decisions.md) перечисляет ключевые сценарии при изменении механик.

Для материалов с историческими именами сохранены пути, на которые ссылается обновлённый GDD.

Упомянутый в обновлённом GDD большой черновик `How_to_Suck_Gameplay_Rework_v1_RU.md` не был добавлен в историю репозитория. Подтверждённые правила опубликованы в документах выше.
